# Сайт курса «Введение в Python»

Одностраничный лендинг курса «Программирование на языке Python (базовый уровень)»:
72 часа, 36 занятий, 14 разделов — от первой программы до защиты итогового проекта.
Сделан как обычная статическая веб-страница, без сборки и без сервера.

## Структура файлов

```
index.html   — разметка страницы (шапка, статистика, карточки, разделы)
style.css    — оформление (светлая/тёмная тема, карточки, адаптивная вёрстка)
script.js    — данные курса (14 разделов × занятия) и код, который строит
               из них раскрывающиеся блоки на странице
README.md    — этот файл
```

## Как открыть

Никакой установки не требуется — просто откройте `index.html` двойным кликом
в любом браузере (Chrome, Safari, Edge, Firefox). Все три файла должны лежать
в одной папке, иначе не подключатся стили и список занятий.

## Как отредактировать содержание

Все занятия и разделы описаны одним массивом `topics` в начале `script.js`:

```js
const topics = [
  { n: 1, title: "...", hours: 4, lessons: [
      { n: 1, title: "...", practice: "..." },
      { n: 2, title: "...", practice: "..." },
  ]},
  ...
];
```

Чтобы изменить текст занятия, добавить новый раздел или поправить количество
часов — правьте только этот массив, вёрстка соберётся из него автоматически.
Остальной текст страницы (заголовок, статистика вверху, карточки «Материалы
курса») — обычный HTML в `index.html`, его можно менять напрямую.

Тема (светлая/тёмная) переключается автоматически по настройке системы; чтобы
жёстко закрепить одну тему, добавьте в `index.html` атрибут
`<html data-theme="light">` или `data-theme="dark"`.

## Как разместить в интернете

Файлы статические, поэтому подходит любой бесплатный статический хостинг —
загрузить папку целиком без дополнительных настроек:

- **GitHub Pages** — создать репозиторий, положить файлы в корень (или в
  папку `docs/`), включить Pages в настройках репозитория.
- **Vercel** / **Netlify** — перетащить папку в веб-интерфейс деплоя
  (drag-and-drop), ссылка появится сразу после загрузки.

## Что это не делает

Это одна страница-программа курса, а не набор отдельных страниц-презентаций
на каждое занятие (как в примере, на который ориентировались). Слайды
вводного мастер-класса и файл КТП существуют отдельно (presentation.pptx и
Word-документ) и на этом сайте не хостятся — они только упомянуты как
карточки в разделе «Материалы курса».
